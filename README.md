# MeroHisab

[![Version](https://img.shields.io/badge/version-1.0.0-blue)](https://github.com/solo-developer/MeroHisab/releases)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-React%20Native-orange)](https://reactnative.dev/)

MeroHisab is a simple, friendly, and offline-first personal finance app that helps you track your daily income and expenses. Designed for mobile, it provides an intuitive interface to manage your money effortlessly.

---

## 🚀 Features

- Track **income and expenses** easily  
- **Clean, minimal UI** optimized for mobile  
- Offline-first using **SQLite database**  
- **Category-based transactions** for better organization  
- Quick **balance and summary views**  
- Works on **Android & iOS** (React Native)
